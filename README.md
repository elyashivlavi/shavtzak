# שבצ"ק מוצב 🪖

מערכת פשוטה לניהול שבצ"ק (שיבוץ שמירות ופטרולים) למוצב קטן, בנויה כולה על **Google Sheets + Google Apps Script** — חינמי לגמרי, בלי שרת ובלי אירוח חיצוני.

## מה המערכת עושה

- **חלוקה הוגנת** — אלגוריתם שמעלה לשמירה בכל 24 שעות את מי שצבר הכי מעט שעות שמירה.
- **מנגנון טיוטה → אישור → פרסום** — אתה עורך שיבוץ בפרטיות; החיילים רואים אותו רק אחרי שאתה לוחץ "אישור ופרסום".
- **הפרדת הרשאות דרך חשבון גוגל** — המנהל עורך, החיילים רק צופים. כל חייל רואה "מתי אני עולה" באופן אישי.
- **ניהול חיילים** — הוספה והורדה בלחיצה, כולל תפקידים (קצין מוצב, סמל) וסימון מי כשיר לעמדות.

## הלוגיקה (ברירת מחדל)

- הרוטציה מעוגנת ל־**12:00 בצהריים** ומתחלפת כל 24 שעות.
- **4 שומרים** בכל בלוק, משמרות של **3 שעות** (כל שומר = 2 משמרות ביום, עם 9 שעות מנוחה ביניהן).
- כל מי שבשמירה נמצא ב**כוננות** לאורך כל ה־24 שעות.
- שאר החיילים הפעילים ב**פטרול** (בוקר + ערב).
- **אסי פרץ (סמל)** מסומן פנימית כתמיד־בפטרול — לא נכנס לרוטציית העמדות, והסיבה לא מוצגת בממשק הציבורי.

כל הפרמטרים ניתנים לשינוי בטאב `config` בגיליון.

## התקנה (פעם אחת, ~5 דקות)

1. היכנס ל־[sheets.new](https://sheets.new) וצור גיליון חדש. תן לו שם, למשל "שבצ״ק מוצב".
2. בתפריט: **Extensions → Apps Script** (תוספות → Apps Script).
3. מחק את הקוד לדוגמה, והדבק **2 קבצים בלבד** מתיקיית `apps-script/`:
   - ב־`Code.gs` הקיים — הדבק את כל התוכן של `apps-script/Code.gs` (כולל ההתקנה).
   - קובץ חדש **File → New → HTML** בשם `Index` — הדבק את `apps-script/Index.html`.
   - (אופציונלי) ב־Project Settings סמן "Show appsscript.json" והדבק את `apps-script/appsscript.json`.
4. בחר למעלה את הפונקציה **`setup`** ולחץ **Run**. אשר את ההרשאות שגוגל מבקשת. זה יוצר את כל הטאבים ומזין את רשימת החיילים.
5. **Deploy → New deployment → סוג: Web app**:
   - **Execute as:** Me (אתה)
   - **Who has access:** Anyone with Google account (או "Anyone within [הארגון]" אם יש)
   - לחץ **Deploy** והעתק את כתובת ה־Web app.
6. שלח את הכתובת לחיילים. הם ייכנסו עם חשבון הגוגל שלהם ויראו את הלוח.

## התקנה חלופית דרך clasp (למי שנוח לו עם טרמינל)

במקום העתק-הדבק, אפשר להעלות הכל בפקודה אחת מהמחשב שלך:

```bash
npm install -g @google/clasp
clasp login                                    # הזדהות בדפדפן — פעם אחת
cd apps-script
clasp create --type sheets --title "שבצ״ק מוצב"
clasp push                                     # מעלה את Code.gs + Index.html
clasp open                                     # פותח את הפרויקט
```
אחר כך: הרץ `setup` פעם אחת, ואז Deploy → New deployment → Web app.

## שימוש יומיומי

**אתה (מנהל):**
1. לשונית **טיוטה** → "ייצר שיבוץ הבא" → המערכת מציעה שיבוץ הוגן ל־24 השעות הבאות.
   - אם מישהו חייב להישאר בפטרול באותו בלוק, פתח "חייבים בפטרול בבלוק הבא" וסמן אותו לפני הייצור — הוא לא יעלה לעמדות.
2. אם צריך — ערוך ידנית כל משמרת שמירה (החיילים עדיין לא רואים).
3. "✓ אישור ופרסום" → עכשיו זה גלוי לכולם.

**חייל:**
- נכנס לכתובת, לשונית **מתי אני עולה** מראה את המשמרות האישיות שלו; **לוח שיבוצים** מראה את הכל.

## הערות

- כדי שחייל יראה צפייה אישית ("מתי אני עולה"), הזן את **המייל (גוגל)** שלו בלשונית "חיילים". בלי מייל הוא עדיין רואה את הלוח הכללי.
- שינוי פרמטרים (מס' שומרים, שעות פטרול וכו') — ישירות בטאב `config` בגיליון.
- הורדת חייל מסמנת אותו כלא־פעיל ושומרת את ההיסטוריה והצבירה שלו.

## מבנה הנתונים (טאבים בגיליון)

| טאב | תפקיד |
|-----|--------|
| `soldiers` | רשימת חיילים: שם, מייל, תפקיד, פעיל, כשיר לעמדות, הערה פנימית |
| `schedule_draft` | השיבוץ שבעריכה — פרטי למנהל |
| `schedule_published` | השיבוץ הגלוי לחיילים |
| `stats` | צבירת שעות שמירה לכל חייל (בסיס ההוגנות) |
| `config` | פרמטרים |
